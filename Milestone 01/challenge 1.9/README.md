# Vibe vs. Pair Challenge

This challenge involves building the same Task Manager application twice to compare two distinct AI-assisted development workflows: **Vibe Coding** (using generative UI/app tools) and **AI Pair Programming** (using editor-integrated assistants). By the end, you'll have a clear understanding of the strengths and weaknesses of each approach.

---

## The App You Are Building

You will be building a standalone Task Manager. You must strictly follow the requirements outlined in the [app-spec.md](./app-spec.md) file for both versions.

## Comparison Table

Fill out the following table after completing both versions:

| Dimension          | Vibe Version (v0)                                         | Pair Version (GitHub Copilot)                            |
| :----------------- | :-------------------------------------------------------- | :------------------------------------------------------- |
| **Speed**          | Generated full app in ~8–10 minutes using a single prompt | Took ~30–40 minutes building manually with AI assistance |
| **Control**        | Limited control — structure and logic auto-generated      | Full control over components, state, and logic           |
| **Code Quality**   | Some large components and unnecessary abstraction         | Clean, modular code with proper separation               |
| **Explainability** | Harder to understand generated hooks and logic            | Easy to explain since code was written step-by-step      |
| **Editability**    | Harder to modify due to scattered logic                   | Easy to extend and modify features                       |

## When I Would Use Each Tool

* **Vibe coding tool:** For quick prototypes and idea validation — because it generates a working app very fast with minimal effort.

* **AI pair programming:** For real-world or production projects — because it provides full control, better code quality, and easier maintainability.
